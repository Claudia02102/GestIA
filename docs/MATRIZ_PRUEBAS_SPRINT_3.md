# Matriz de aceptación — Sprint 3 (Épica E3)

Estado: **pendiente de ejecución con webcam real**. Antes de empezar: perfil calibrado (si
viene del Sprint 2, pulse **Calibrar** una vez para incluir «Fruncir los labios»), casilla
*Controlar el cursor del sistema* marcada. Para recuperar el ratón en cualquier momento:
**Ctrl+Alt+P**. Anote el escalado de pantalla de Windows (Configuración → Pantalla).
