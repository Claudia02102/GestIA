# Matriz de aceptación — Sprint 4 (Épica E4: Escritura en pantalla)

Estado: **pendiente de ejecución con webcam real**. Antes de empezar: perfil calibrado, casilla
*Controlar el cursor del sistema* marcada y, si se desea, clic por permanencia activo
(*Puntero*). Abra el Bloc de notas o Word y pulse **Mostrar teclado**. Para recuperar el ratón
en cualquier momento: **Ctrl+Alt+P**.
